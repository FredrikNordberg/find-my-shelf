# FindMyShelf – Demo Store Product Finder

Welcome to **FindMyShelf**, a modern demo web app for quickly locating products in a store!  
It’s built with **Next.js (App Router)** and **Tailwind CSS** – designed to be fast, responsive, and simple to use.  

---

## 🚀 What is this?

This project is a prototype of a **store product finder application**.  
The idea is to make it easy for customers (or staff) to:

- Search for products by name  
- Filter by category  
- See location codes (aisle, shelf)  
- View a full product detail page with specifications  
- Display images (or fallback placeholders)  

It’s a demo intended for learning, inspiration, and showcasing how modern web tools can build a clean and efficient store assistant.

---

## 🛠️ Tech Stack

- Next.js 13+ (App Router)  
- React  
- Tailwind CSS  
- JSON (mock database)  

---

## 📱 Features

- 🔎 Live search with instant filtering  
- 🏷️ Category filters  
- ⭐ Popular products section on homepage  
- 📄 Detailed product page with specs  
- 🖼 Placeholder images for missing product photos  
- 📱 Fully responsive design (desktop & mobile)
